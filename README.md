# Parasha Blocker

A browser extension that hides all russian and pro-russian websites in search results.
It also hides news and all images from the corresponding tab for blocked sites.

Works in Google Chrome with the following search engines (Results Tab):
1. DuckDuckGo
2. Google
3. Bing

Works in Mozilla Firefox with the following search engines (Results / Image Tab):
1. DuckDuckGo

## How to Install
1. Install .zip archive from Releases
### For Google Chrome
2. Open [chrome://extensions/](chrome://extensions/)
3. In the top-right corner, enable **Developer mode**
4. In the top-left corner, click **Load unpacked**
5. Select the folder containing the unpacked extension
6. Done
### For Mozilla Firefox
2. Open [about:debugging](about:debugging#/runtime/this-firefox)
4. Click **Load temporary Add-on**
5. Select the folder containing the unpacked extension
6. Done
